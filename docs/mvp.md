# MVP Specification

## Goal

Validate that people want to find nearby hobbyists with shared interests.

## User Features

### Accounts
- Username
- Phone verification
- Approximate location

### Hobby Profiles
- Select hobbies
- Select experience level

### Discovery
- View nearby users
- View shared interests
- View approximate distance

### Connections
- Send connection requests
- Accept connection requests

## Not Included

- News feed
- Followers
- Marketplace
- Public ratings
- Livestreams
- Reels
- Open messaging

## MVP Success

A user discovers another nearby person with a shared interest and sends a connection request.
